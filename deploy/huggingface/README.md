# RuleSmith (hosted demo)

Autonomous detection-engineering agent built on NVIDIA Nemotron via Nebius Token Factory.
Source and documentation: https://github.com/Arekkusul/nebius-nvidia-hackathon

Set `NEBIUS_API_KEY` (and optionally `TAVILY_API_KEY`) as Space secrets to enable live runs.
With `RULESMITH_DEMO_LOCKED=true` visitors can only run the bundled example reports.
