How it works
  1. Ingest Tavily Search / Extract, or a direct fetch.
  2. Extract Nemotron 3.5 Lightning pulls behaviours, ATT&CK ids and evidence quotes.
  3. Plan Nemotron 3 Ultra decides which behaviours deserve rules, thinking on.
  4. Author Nemotron 3 Super writes each Sigma rule and its test events, grounded on SigmaHQ.
  5. Validate No model: pySigma parse, field dictionary, ATT&CK index, compile to SQL, run the tests and a 2,390-event benign baseline.
  6. Refine Failures go back with the exact event, selection and field.
  7. Red-team Ultra invents evasions; the rule is hardened against them.
  8. Package Sigma, Splunk, Elastic, KQL, tests, Navigator layer, report.
