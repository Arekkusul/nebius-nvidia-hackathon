How it works
  1. Ingest — Tavily Search / Extract (or direct fetch).
  2. Extract — Nemotron 3.5 Lightning pulls behaviours, ATT&CK ids and evidence quotes (strict JSON schema, thinking off).
  3. Plan — Nemotron 3 Ultra decides which behaviours deserve rules and how to keep them specific (thinking on).
  4. Author — Nemotron 3 Super writes each Sigma rule and its positive/negative test events, grounded on SigmaHQ rules for the same logsource and technique.
  5. Validate — no LLM: pySigma parse, field dictionary, ATT&CK index, compile to SQL, execute against the tests and a 2,390-event benign baseline.
  6. Refine — failures go back to Super with the exact events it got wrong, per selection and per field.
  7. Red-team — Ultra invents evasions; the rule is hardened against them.
  8. Package — Sigma + Splunk + Elastic + KQL + tests + ATT&CK Navigator layer.
